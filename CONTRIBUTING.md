# Contributing to Decanet

Спасибо за интерес к проекту! Мы рады видеть ваш вклад.

## Как начать

1. **Fork репозиторий** на GitHub
2. **Clone** ваш fork локально
3. **Создайте новую ветку** для вашей фичи или исправления:
   ```bash
   git checkout -b feature/название-фичи
   ```
4. **Сделайте изменения** в коде
5. **Протестируйте** ваши изменения
6. **Коммитьте** с понятными сообщениями:
   ```bash
   git commit -m "feat: описание изменения"
   ```
7. **Push** на ваш fork
8. **Создайте Pull Request** в основной репозиторий

## Стиль кода

Мы используем **PSR-12** стандарт кодирования для PHP.

Проверьте код перед коммитом:
```bash
composer lint
```

Автоматически исправьте стиль:
```bash
composer lint-fix
```

## Типы коммитов

- `feat:` — новая функция
- `fix:` — исправление ошибки
- `docs:` — документация
- `style:` — форматирование кода
- `refactor:` — рефакторинг без изменения функциональности
- `test:` — добавление тестов
- `chore:` — обновление зависимостей

Пример:
```bash
git commit -m "feat: add 2FA authentication module"
git commit -m "fix: correct database connection issue"
```

## Тестирование

Перед отправкой PR убедитесь, что все тесты проходят:

```bash
composer test
```

## Сообщение об ошибках

Если вы нашли ошибку, создайте Issue с:
- Описанием проблемы
- Шагами для воспроизведения
- Ожидаемым поведением
- Фактическим поведением
- Версией PHP и окружением

## Pull Request процесс

1. Обновите `README.md` если необходимо
2. Обновите версию в `composer.json` если это нужно
3. Дождитесь review от мейнтейнеров
4. Исправьте замечания если они есть

## Лицензия

Отправляя PR, вы соглашаетесь с тем, что ваш код будет лицензирован под MIT лицензией.
